## Overview

This Bakery Website is a modern web application built to help customers explore a local bakery’s offerings, learn about the business, and easily place inquiries or orders.

It is designed with a clean, responsive interface and a scalable architecture that can later support online ordering, payments, and inventory management.

### Goals

- Showcase fresh baked goods in an attractive, easy-to-browse menu
- Provide a smooth and mobile-friendly customer experience
- Support online inquiries and custom order requests
- Build a scalable foundation for future e-commerce features
- Keep performance fast and SEO-friendly for local discovery

---

### Features

- [x] Responsive bakery menu (breads, pastries, specialty items)
- [x] Home page with featured products and bakery introduction
- [x] About page with bakery story and values
- [x] Contact form for custom orders and inquiries
- [x] Mobile-friendly responsive UI
- [x] SEO-friendly routing with Next.js App Router
- [ ] Online ordering system
- [ ] Payment integration
- [ ] Admin dashboard for managing products
- [ ] Email notifications for orders

---

### Software Stack / Technologies Used

- **Framework:** Next.js (App Router)
- **Language:** TypeScript
- **Frontend:** React, Tailwind CSS
- **Backend:** FastAPI
- **Database:** PostgreSQL
- **Version Control:** Git, GitHub
